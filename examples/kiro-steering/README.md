# Kiro Steering — примеры для 1C Debug MCP

Готовые [Kiro Steering](https://kiro.dev/docs/steering) файлы для работы с MCP сервером отладки 1С.

## Файлы

### `1c-debug-mcp.md` — правила отладки

Инструкции по использованию всех 13 инструментов MCP сервера.
Активируй когда нужна отладка 1С кода.

### `1c-debug-setup.md` — быстрая настройка отладки в проекте

Пошаговый сценарий для Kiro: задаёт нужные вопросы и создаёт `.kiro/settings/mcp.json`.
Активируй когда нужно добавить отладку в новый проект.

## Установка

Скопируй нужные файлы в одну из папок:

- `~/.kiro/steering/` — глобально для всех проектов
- `.kiro/steering/` — только для текущего проекта

## Использование

Оба файла настроены как `inclusion: manual` — не загружаются автоматически.

В чате Kiro:
- `#1c-debug-mcp` — активировать правила отладки
- `#1c-debug-setup` — активировать настройку отладки в проекте
