# Kiro Steering — пример для 1C Debug MCP

Этот файл — готовый [Kiro Steering](https://kiro.dev/docs/steering) для работы с MCP сервером отладки 1С.

## Установка

Скопируй `1c-debug-mcp.md` в одну из папок:

- `~/.kiro/steering/` — глобально для всех проектов
- `.kiro/steering/` — только для текущего проекта

## Использование

Steering настроен как `inclusion: manual` — он не загружается автоматически,
а подключается вручную когда нужна отладка.

В чате Kiro напиши `#1c-debug-mcp` чтобы активировать правила.

После этого Kiro будет автоматически использовать MCP инструменты отладки
при любых запросах связанных с отладкой 1С кода.
