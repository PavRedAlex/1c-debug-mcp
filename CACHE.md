# Кэш метаданных

## Что это?

MCP-сервер автоматически кэширует метаданные конфигурации 1С для быстрого старта.

## Как это работает?

### Первый запуск
- Сканирует все XML файлы конфигурации
- Строит карту UUID → имя модуля
- Сохраняет в `.1c-debug-metadata-cache.json`

### Последующие запуски
- Проверяет актуальность кэша
- Если актуален — загружает за <100мс
- Если нет — пересканирует

## Когда кэш обновляется?

Автоматически при:
- Изменении `Configuration.xml`
- Добавлении/удалении модулей (изменяется mtime папки)
- Изменении путей в конфигурации MCP
- Обновлении версии MCP-сервера

## Где хранится?

Рядом с вашей конфигурацией:
```
C:/Projects/MyConfig/
├── Configuration.xml
├── .1c-debug-metadata-cache.json  ← здесь
├── CommonModules/
└── ...
```

## Нужно ли коммитить в git?

**Нет** — файл уже добавлен в `.gitignore`.

Кэш создается автоматически и специфичен для каждой машины.

## Ручное обновление

Если нужно принудительно обновить кэш:

```javascript
// В Kiro или другом MCP клиенте

// Обычное обновление - использует кэш если он валиден
mcp_1c_debug_reload_metadata()

// Принудительное пересканирование - игнорирует кэш
mcp_1c_debug_reload_metadata({ skipCache: true })
```

**Когда использовать `skipCache: true`:**
- Кэш кажется поврежденным или устаревшим
- Тестирование производительности загрузки
- Отладка проблем с кэшем
- После ручных изменений файловой системы, которые не обновили mtime папок

Или просто удалите файл `.1c-debug-metadata-cache.json` — он пересоздастся при следующем запуске.

## Производительность

| Размер конфигурации | Без кэша | С кэшем |
|---------------------|----------|---------|
| 100 модулей         | 1с       | <50мс   |
| 500 модулей         | 8с       | <100мс  |
| 1000 модулей        | 25с      | <150мс  |

## Устранение неполадок

**Кэш не создается?**
- Проверьте права на запись в папку конфигурации
- Убедитесь что `Configuration.xml` существует

**Устаревшие данные?**
- Используйте инструмент `reload_metadata`
- Или измените `Configuration.xml` (даже пробел) для инвалидации

**Большой размер файла?**
- Это нормально для больших конфигураций (1-5 МБ)
- Кэш — это JSON с UUID и именами всех модулей
